How the Developer flow is made. The PromptLens CLI links local Claude Code sessions to each commit, summarizes every developer request (prompt → what the AI did → outcome → prompt review) into a git note, and the GitHub Action posts the flow on the pull request. This page shows that same data for NewCodes7/promptlens#1, exported with scripts/export-hub-data.mjs. Prompts are quoted verbatim after secret redaction; English translations are added for this page.

Samples. Designer, Marketer, Professional and Founder flows are illustrative, hand-written examples of where PromptLens goes next. Their people, comments and reactions are not real. The discussion box is a demo and does not save.
